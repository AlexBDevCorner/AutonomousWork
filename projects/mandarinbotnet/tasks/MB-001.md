# MB-001 — Bootstrap MandarinBotNet autonomous execution wiring

## Goal

Prove that the existing AutonomousWork dispatcher can claim a MandarinBotNet
task, invoke the target repository worker, and complete the normal
task → PR → review lifecycle without touching application behavior.

## Context

- Project: `mandarinbotnet` (`projects/mandarinbotnet/project.yaml`).
- Target repo: `AlexBDevCorner/MandarinBotNet`.
- Default target branch: `main`.
- Worker: `.github/workflows/autonomous-worker.yml` in the target repository.
- This is the first end-to-end task for MandarinBotNet and should remain a
  deliberately small docs-only pilot.

## Requirements

1. Create `docs/autonomous-runs/MB-001.md` in the target repository.
2. In that report, record:
   - the pinned AutonomousWork control specification used for the run;
   - confirmation that `projects/mandarinbotnet/project.yaml` maps exactly to
     `AlexBDevCorner/MandarinBotNet`;
   - the real baseline build/test commands and their results for the target
     repository.
3. Do all work on branch `autonomous/MB-001` from `main`.
4. Open exactly one PR to `main` satisfying the normal autonomous PR contract:
   - title starts with `[MB-001]`;
   - labels `autonomous`, `autonomous:opencode`, `task:MB-001`;
   - body sections `Task`, `Control specification`, `Implementation`,
     `Verification`, and `Autonomous execution`.
5. Do not change product code, tests, infrastructure, workflows, package
   versions, or project configuration as part of this pilot.

## Architectural direction

This task exists only to prove MandarinBotNet onboarding.

The target change must be documentation-only. The worker may create
`docs/autonomous-runs/MB-001.md` and update the PR description, but must not
modify application code, tests, `.github/`, deployment configuration, or this
control repository.

## Acceptance criteria

- [ ] `docs/autonomous-runs/MB-001.md` exists in the target repository and
      contains the pinned control spec plus real build/test evidence.
- [ ] The report confirms the control project maps only to
      `AlexBDevCorner/MandarinBotNet`.
- [ ] Exactly one PR exists from `autonomous/MB-001` to `main`.
- [ ] The PR satisfies the autonomous title/labels/body contract.
- [ ] No application, test, workflow, infrastructure, or package changes are
      included.
- [ ] The dispatcher/reconciler lifecycle advances the task according to the
      normal AutonomousWork contract.

## Verification

Required target-repository verification:

```sh
dotnet build MandarinBotNet.sln
dotnet test MandarinBotNet.sln
```

Also confirm the resulting PR targets `main`, carries the required labels,
and records the pinned control specification exactly.

## Out of scope

- Application behavior changes.
- Scheduler implementation; that belongs to MB-002.
- Changes to `projects/mandarinbotnet/project.yaml`.
- Changes to AutonomousWork dispatcher/reconciler behavior.
- Changes to priorities, dependencies, or any other task.
