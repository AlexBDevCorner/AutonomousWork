# MSS-102 — Qualify top 16 and draw each subsequent Chaos stage

## Goal

Advance the completed current stage to a new random unseeded draw and eventually Final standings.

## Context

- Project `mtgsolosports`, target `AlexBDevCorner/MtgSoloSports` (`main`). .NET + React, direct vertical-slice Endpoint → Handler, no MediatR; follow `AGENTS.md`. Approved Chaos Cup: 8 sporting colors, 1024 entrants (all source-season league athletes plus random Pool invitations), six 32-athlete group stages [32,16,8,4,2,1], top 16 from each nonfinal group; 16 game rounds per group, active bonus used but not earned; no league points/promotion, group scores reset; first draw exactly 4/color/group, later draws pure random. Runs after 32 league stages and before promotion qualifiers, only for a new season after deployment; odd/even Color/Type Cups keep alternating. Existing sporting history must remain unchanged.
- Scope: **Qualify top 16 and draw each subsequent Chaos stage**. This is a single small PR, target roughly 200–600 changed lines where practical; if work expands materially, propose follow-up rather than bundling unrelated features.
- Dependencies: MSS-101; tasks with incomplete dependencies must wait.

## Requirements

1. Allow next-stage draw only after all current groups complete; advance exactly 16 per group, reset scores and create fresh 32-athlete groups.
2. Stages shrink groups 32→16→8→4→2→1, completely random after first stage with no color or tier constraints.
3. Persist once-only stage draw and independent group RNG irrespective of group execution order; never reroll on request retry.
4. After the sixth 32-athlete Final persist P1..P32 and exit-stage classification for all other entrants, without inventing precise ranks 33..1024.

## Architectural direction

- Reuse existing feature/simulation/report patterns; keep deterministic integer calculations, save-scoped state and clear compatibility boundaries. Do not introduce MediatR or unrelated refactors.

## Acceptance criteria

- [ ] Qualification counts and exact Final field pass invariant tests.
- [ ] Mixed group completion order yields same next draws and no duplicated qualified athlete.

## Verification

`dotnet build MtgSoloSports.slnx --configuration Release` and `dotnet test MtgSoloSports.slnx --configuration Release` from target root. Add focused regression tests for the task's acceptance criteria and validate compatibility with prior editions. 

## Out of scope

- No medals, career scoring, automatic all-Cup completion or UI.
- Do not implement any other task or modify unrelated history/data merely for convenience.
