# MSS-003 — Implement scoring, bonus decay and deterministic tie-breaking

## Goal

Implement the pure sporting mathematics needed by rounds, stages, standings and Cups.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `main`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Implement the exact 32-position base/championship scoring table from Game Rules v1.
2. Implement effective round points using fixed-point arithmetic: base points multiplied by `(1 + active bonus)` without floating point.
3. Implement regular-league and doubled-Superleague bonus award tables.
4. Implement linear seasonal contribution weights 100/80/60/40/20/0, including Stage 32 contributions entering the next season at 80%.
5. Implement deterministic generic ranking/tie-break helpers capable of comparing placement-count vectors, raw totals and a supplied seeded final draw only when all deterministic fields tie.
6. Add exhaustive unit tests for boundary positions, decay ages, Superleague multiplier and tie cases.

## Architectural direction

- Keep these as pure `SimulationKernel` functions/value types; do not depend on persistence models.
