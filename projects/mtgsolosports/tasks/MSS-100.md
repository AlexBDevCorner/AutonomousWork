# MSS-100 — Select 1024 entrants and persist balanced first-round draw

## Goal

Freeze all league entrants and randomly invite Pool athletes to produce 32 groups with four of every color.

## Context

- Project `mtgsolosports`, target `AlexBDevCorner/MtgSoloSports` (`main`). .NET + React, direct vertical-slice Endpoint → Handler, no MediatR; follow `AGENTS.md`. Approved Chaos Cup: 8 sporting colors, 1024 entrants (all source-season league athletes plus random Pool invitations), six 32-athlete group stages [32,16,8,4,2,1], top 16 from each nonfinal group; 16 game rounds per group, active bonus used but not earned; no league points/promotion, group scores reset; first draw exactly 4/color/group, later draws pure random. Runs after 32 league stages and before promotion qualifiers, only for a new season after deployment; odd/even Color/Type Cups keep alternating. Existing sporting history must remain unchanged.
- Scope: **Select 1024 entrants and persist balanced first-round draw**. This is a single small PR, target roughly 200–600 changed lines where practical; if work expands materially, propose follow-up rather than bundling unrelated features.
- Dependencies: MSS-098, MSS-099; tasks with incomplete dependencies must wait.

## Requirements

1. Select all actual source-season league participants; invite distinct uniform-random Pool members per color per MSS-098, with no strength/bonus/league weighting.
2. Freeze source league tier/Pool, color, athlete identity and effective-bonus context for this edition before promotion/rebalancing.
3. Persist 32×32 first draw with exactly 4 of each color per group, group RNG and immutable result; retry cannot reroll/double-consume sporting RNG.
4. Test 800-active ordinary season, 768-active Season 1 and skewed Superleague color composition.

## Architectural direction

- Reuse existing feature/simulation/report patterns; keep deterministic integer calculations, save-scoped state and clear compatibility boundaries. Do not introduce MediatR or unrelated refactors.

## Acceptance criteria

- [ ] Exactly 1024 unique entrants, each first group 4×8 colors and all source-season actives included.
- [ ] Same seed/state yields exactly same draw; retries idempotent.

## Verification

`dotnet build MtgSoloSports.slnx --configuration Release` and `dotnet test MtgSoloSports.slnx --configuration Release` from target root. Add focused regression tests for the task's acceptance criteria and validate compatibility with prior editions. 

## Out of scope

- No games, future draws or athlete movement.
- Do not implement any other task or modify unrelated history/data merely for convenience.
