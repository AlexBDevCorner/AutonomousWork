# MSS-022 — Add official honours, records and Hall of Fame

## Goal

Turn accumulated history into long-term career comparison and record-chasing views.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `main`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Persist/update official league/Superleague honours and podium/placement statistics as applicable.
2. Implement query projections for major records available before Cups: Superleague/feeder titles, stage wins, round wins, longest Superleague tenure, appearances, promotion/relegation counts, highest effective bonus and notable streaks.
3. Keep record-holder changes/history where practical so new records can emit story events.
4. Add Hall of Fame/records endpoints and React views with athlete navigation.
5. Do not compute common records by decompressing all raw round payloads.
6. Add tests for record creation, tie behavior and record replacement.

## Architectural direction

- Record projections are query accelerators and must be rebuildable/auditable from authoritative history.
