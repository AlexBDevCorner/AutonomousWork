# MSS-024 — Implement the Color Cup individual competition

## Goal

Run the 32 selected color representatives through the official post-season individual Cup.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `main`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Run one standard 16-round stage with all 32 selected Color Cup athletes.
2. Use their active career bonus but award no new career bonus and no league championship points.
3. Award/persist Gold, Silver, Bronze and the official Color Cup individual championship.
4. Keep Cup results separate from normal league season standings while updating career Cup honours/history.
5. Persist complete round/stage result for exact replay.
6. Expose Cup result API/read model and add a basic result UI.
7. Add tests proving Cup participation cannot change career bonus.

## Architectural direction

- Reuse sporting kernel primitives; keep Cup orchestration/history in the Color Cup slice.
