# MSS-013 — Add athlete career profile and season-history projections

## Goal

Make athletes feel persistent by exposing their career identity and season-by-season sporting history.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `master`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Introduce/update transactional athlete career and season summary projections as league stages/seasons complete.
2. Track at least seasons active, current status/league, round wins, stage wins, stage podium counts, season finish, effective/current bonus and lifetime earned bonus.
3. Expose an athlete profile endpoint including season-by-season history and current creature/sporting metadata.
4. Add a React athlete profile page reachable from standings/live-round card rows.
5. Keep projections rebuildable/auditable from authoritative history; do not make UI-only counters the source of truth.
6. Add tests for projection updates across multiple stages and seasons/common-pool inactivity where data exists.

## Architectural direction

- Avoid loading/decompressing all historical rounds to render a normal athlete profile.
