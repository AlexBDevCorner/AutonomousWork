# MSS-020 — Build historical season/stage/round navigation and exact replay

## Goal

Make persisted history browsable without resimulating old sporting events.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `main`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Expose history queries for season -> competition -> stage -> round using normalized summaries plus the immutable compressed round payload.
2. Decompress historical round payload only when that exact round is requested.
3. Add React history navigation with season/stage/round selection and exact historical standings/result views.
4. Allow an old round to feed the same presentation model used by live results.
5. Historical replay must not consume RNG or mutate save state.
6. Add tests proving replay returns the originally persisted result after future seasons have advanced.

## Architectural direction

- Do not scan/decompress all rounds to build season lists or ordinary statistics.
