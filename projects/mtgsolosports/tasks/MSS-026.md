# MSS-026 — Implement Type Cup eligibility, matching and permanent nationality

## Goal

Build deterministic four-athlete creature-type teams while resolving multi-type athlete conflicts and football-style permanent allegiance.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `main`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Eligible candidates are currently active athletes only and may initially represent any printed creature type unless already capped.
2. A capped athlete may represent only its permanent Type Cup nationality.
3. For uncapped athletes, preference favors the type where the athlete has the stronger relative team ranking (for example #1 Wizard over #4 Human).
4. Implement a deterministic global allocation that maximizes the number of valid four-distinct-athlete teams while respecting permanent nationality and preference/tie rules.
5. Only types that actually receive four distinct athletes participate; there is no artificial maximum team count.
6. Persist the allocation and each athlete's selection score/rank explanation.
7. Do not set permanent nationality merely by being considered/selected in an allocation preview; nationality becomes permanent when the athlete actually participates.
8. Add difficult overlap tests such as the same four Human Wizards being the only candidates for both teams.

## Architectural direction

- Keep the matching algorithm deterministic and extensively unit-tested; do not use random assignment to solve conflicts.
