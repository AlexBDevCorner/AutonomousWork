# MSS-007 — Initialize Season 1 leagues and the common pools

## Goal

Start a new universe with eight 32-athlete feeder leagues and correctly initialized common pools.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `main`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Create Season 1 with no Superleague.
2. For each sporting color, draw exactly 32 athletes from its 256-athlete save population using the controlled RNG.
3. Create membership/history data so an athlete is in exactly one active league or the common pool.
4. Persist the draw order/result so the inaugural draw can be presented later without resimulation.
5. Expose a read endpoint returning inaugural league rosters and remaining pool counts.
6. Validate eight leagues × 32 active athletes = 256 active and no duplicates.
7. Add invariants and deterministic seed tests.

## Architectural direction

- Model current membership separately from permanent athlete identity/history; do not encode league membership in card metadata.
