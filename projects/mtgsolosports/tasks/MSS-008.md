# MSS-008 — Simulate and persist a single league round

## Goal

Make the first real sporting event work end to end: deterministic shuffle, points, immutable result, RNG advancement and API response.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `master`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Add an `AdvanceRound` vertical slice for the currently legal league/stage.
2. Shuffle all 32 athletes using only the save RNG and award base points by position.
3. Calculate final points using only bonus active at the start of the stage.
4. Persist one Round row with a compact immutable payload containing athlete order, base points, active bonus, final points and enough before/after cumulative data for replay/rank movement.
5. Persist RNG-after state in the same transaction as the round result.
6. Return an immutable presentation DTO usable by instant and future animated UI.
7. Reject illegal duplicate/out-of-order round execution.
8. Add determinism and transaction/invariant tests.

## Architectural direction

- Do not create 32 placement rows per round; detailed replay belongs in the compact round payload.
- Presentation never drives the simulation.
