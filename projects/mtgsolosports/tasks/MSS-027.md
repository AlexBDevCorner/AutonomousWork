# MSS-027 — Implement the Type Cup team competition

## Goal

Run every valid creature-type team through the rank-group team event and establish nationality on participation.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `main`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Use each allocated team's four athletes ordered #1-#4.
2. Run corresponding rank groups with 8 rounds per group using active bonus and no new bonus.
3. Support the dynamically varying number of participating creature-type teams.
4. Calculate deterministic final team standings and award Gold/Silver/Bronze plus official Type Cup team championship.
5. When an uncapped athlete actually participates, persist that creature type as permanent nationality atomically with the event.
6. Persist complete results/history/replay and expose basic result UI.
7. Update athlete career/Cup projections and story-event extension points.
8. Add tests proving nationality can never change in later Type Cups.

## Architectural direction

- Do not assume exactly eight teams; only Color Cup has a fixed eight-team field.
