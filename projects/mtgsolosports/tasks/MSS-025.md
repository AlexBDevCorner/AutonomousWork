# MSS-025 — Implement the Color Cup team event

## Goal

Run four ranked relay-like groups and combine them into an official eight-color team championship.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `main`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Use each color's selected #1/#2/#3/#4 ordering from selection rating.
2. Run four groups where athletes compete only against the corresponding rank from the other seven colors.
3. Each group has exactly 8 rounds; active career bonus affects points.
4. Generate no new career bonus.
5. Team score is the sum of all four athletes' group scores and uses deterministic tie-breaking.
6. Award/persist team Gold/Silver/Bronze and official Color Cup team championship plus individual group statistics.
7. Persist/replay group results and expose result UI.
8. Add tests that an athlete never competes in the wrong rank group and bonus is not generated.

## Architectural direction

- Model the event generically enough that Type Cup can reuse pure team-event scoring concepts without coupling team identity rules.
