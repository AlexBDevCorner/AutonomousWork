# MSS-006 — Create a 2,048-athlete save universe

## Goal

Create the immutable athlete population for a new save with exactly 256 athletes in each sporting color.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `main`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Add the save-creation universe step selecting exactly 256 unique catalog athletes per each of the eight sporting colors using the save RNG.
2. Total save athlete count must be exactly 2,048 with no duplicates.
3. Copy all save-required card metadata into the save DB so later catalog changes cannot rewrite the universe.
4. Persist athlete creature types, sporting color and artwork reference.
5. All non-active selected athletes initially belong to their color's common pool state.
6. Universe creation and initial RNG advancement must be transactional; failure leaves no partially initialized save.
7. Return a deterministic creation summary suitable for UI display.
8. Add same-seed golden tests and different-seed sanity tests.

## Architectural direction

- Do not query the global catalog during future sporting simulation once the save athlete snapshot exists.
