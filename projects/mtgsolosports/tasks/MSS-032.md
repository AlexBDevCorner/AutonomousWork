# MSS-032 — Complete dashboard, history and spectator-experience polish

## Goal

Bring the implemented systems together into a coherent Football-Manager-like statistics experience plus expressive live-event presentation.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `main`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Dashboard shows season/stage, current Superleague/feeder leaders, recent winners/stories, upcoming event, Cup context and meaningful records.
2. Add clear navigation among competitions, athlete profiles, history, records/Hall of Fame and current live event.
3. Show Superleague color composition and promotion/relegation/qualifier zones without applying quotas.
4. Surface career honours, movements, selections, nationality and important record/story context on athlete pages.
5. Use card artwork prominently where useful with graceful fallback when unavailable.
6. Keep dark MTG-inspired-but-original visual styling consistent and responsive for normal desktop-browser use.
7. Remove obvious seed/placeholder UX and document the standard local run flow.

## Architectural direction

- Polish existing slices; do not create a new frontend architecture or duplicate backend calculations in the client.
