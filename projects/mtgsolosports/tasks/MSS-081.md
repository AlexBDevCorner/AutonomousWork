# MSS-081 — Add individual and combined Color Cup medal tables by color

## Goal

Expand the **Cups** section with two additional all-time Color Cup medal standings, so players can compare how successful each color has been across individual and team competitions. Keep the existing team medal table and its logic unchanged.

## Context

- Project: `mtgsolosports`; target repo: `AlexBDevCorner/MtgSoloSports`, branch `main`.
- Requested 2026-10-15.
- Cups already shows a team medal table by color across Color Cup editions. This table is correct and should remain available without changing its calculation.
- Players also want to see how many medals each color has earned from **individual Color Cup results**, and how colors rank when **individual and team medals are counted together**.
- This is an additive stats/presentation improvement, not a change to competitions or medal awards.

## Requirements

1. **Preserve the existing team standings.**
   - Keep the current all-time Color Cup team medal standings and the existing source/aggregation rules.
   - No changes to historical Cup results, podiums or team medal ownership.

2. **Add an individual medal table grouped by color.**
   - Include only individual Color Cup gold, silver and bronze medals awarded to individual athletes, across all completed Color Cup editions.
   - Credit each individual medal to the color that the athlete **represented in that Color Cup edition** (use the authoritative competition/team-color association or equivalent persisted result; do not simply infer from the athlete's current league, team or mutable properties).
   - Include every supported Color Cup color category, including Multicolor and Colorless when applicable.
   - Aggregate each awarded medal once, not once per appearance, selection or repeated rendering of a historical record.

3. **Add a combined Color Cup medal table grouped by color.**
   - Combine the team medal totals from the **existing** team table and the newly calculated individual medal totals for the same color.
   - For each color: `Gold = Team Gold + Individual Gold`, and likewise for Silver and Bronze; `Total = Gold + Silver + Bronze`.
   - Each team podium award counts as **one medal for its color**, not one medal per athlete in the squad. Each individual podium award counts as one medal.
   - Do not include medals from Type Cup, Superleague or other competitions. No double counting between individual and team records.
   - Make both sets of underlying results auditable against individual Color Cup editions, including historical saves.

4. **Present all three medal tables clearly in Cups.**
   - Give players an obvious way to view **Team**, **Individual** and **Combined** Color Cup medal standings; reuse the current component/table styling where possible (a compact three-option switcher or separate clearly labeled tables, whichever fits the page best).
   - Display color, gold, silver, bronze and total medals, following the current team's medal-table conventions.
   - Rank colors with the **same sorting/tie-break rules as the existing team medal table** (e.g. gold, then silver, then bronze if that is what it currently does); apply consistently to all three views.
   - Make the scope of each table explicit in its heading/label; ensure dark-theme readability and responsive layouts without clutter.
   - Display meaningful zero/empty states for new universes and missing medal categories; do not invent medals or misrepresent unfinished Cups.

5. **Use authoritative persisted results and preserve old universes.**
   - Derive counts from authoritative completed Color Cup historical results rather than snapshots of current rosters or the currently running season.
   - Support loading and displaying previously saved universes without requiring a new save or re-running Cups.
   - Keep API/DTO changes minimal and backward-compatible if the current Cups data does not already include the needed individual medal history.

## Acceptance criteria

- [ ] The existing Color Cup **Team** table produces the same results as before.
- [ ] An **Individual** table shows all-time individual Color Cup G/S/B medals for each color, including Multicolor/Colorless where relevant.
- [ ] A **Combined** table shows, for every color and medal type, the exact arithmetic sum of the Team and Individual tables.
- [ ] One team gold awards **one** gold to its color in Team and Combined, irrespective of roster size; an individual gold adds exactly **one** more to Individual and Combined.
- [ ] Sorting and tie-breaking match the existing medal-table behavior and are consistent across views.
- [ ] Results remain correct after multiple seasons, remapped athlete leagues/teams, page reload and historical save load.
- [ ] In-progress/not-yet-awarded cups and unrelated competition medals do not affect any of the three Color Cup tables.
- [ ] All three tables are readable in the existing Cups page on desktop and narrow viewports.

## Verification

1. Add focused aggregation tests for team-only, individual-only, and mixed historical results; include multiple seasons, colors, tied medal counts, and colors without medals.
2. Add tests for medal assignment using the athlete's Color Cup representation at the time of the award, including later league/team changes.
3. Cross-check Combined = Team + Individual for every color and medal type and ensure team awards are not multiplied by roster size.
4. Add/update Cups UI tests for switching/reading the three views, labels, sorting and empty states.
5. Run the relevant .NET tests and frontend tests/typecheck/build using the existing repository scripts.

## Out of scope

- Changes to Color Cup competition formats, selection, simulation, medal awards or scoring.
- Recalculation/reassignment of previously awarded medals.
- Adding Type Cup or Superleague medals to these color-based Color Cup tables.
- A broad redesign of the Cups page or unrelated standings.
