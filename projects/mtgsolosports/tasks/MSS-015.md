# MSS-015 — Resolve normal automatic Superleague promotion and relegation

## Goal

Implement the fixed automatic movement for completed seasons from Season 2 onward.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `main`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Identify Superleague positions 1-16 as safe, 17-24 as qualifier incumbents and 25-32 as eight automatic relegations.
2. Identify every feeder-league champion as one of eight automatic promotions.
3. Persist structured movement/qualification-candidate data without prematurely filling feeder pools.
4. Returning/relegated athletes keep sporting color and bonus history.
5. Validate exactly eight automatic promotions and eight automatic relegations.
6. Expose postseason movement summary data suitable for dashboard/story use.
7. Add tests for highly unequal color composition and multiple returning athletes to the same feeder color.

## Architectural direction

- Do not enforce any Superleague color quota.
