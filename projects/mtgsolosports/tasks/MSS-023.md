# MSS-023 — Implement Color Cup team selection rating

## Goal

Select four representatives for each sporting color using the agreed mix of bonus, completed-season performance, recent form and historical prestige.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `main`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Calculate four normalized fixed-point components within each color: 35% effective bonus, 30% completed-season performance, 25% recent form and 10% career prestige.
2. Recent form uses the latest ten league stages with deterministic recency weights 1..10 from oldest to newest.
3. Define versioned Rules v1 prestige constants using championships, Superleague success, podiums and available major career achievements; document the initial constants.
4. Select exactly four athletes per each of eight sporting colors and order them #1-#4 by final selection rating.
5. Superleague athletes continue representing their original sporting color.
6. Persist selection scores/components so the user can understand why an athlete was chosen.
7. Add tests where strong recent form or career prestige changes the final team compared with raw bonus ranking.

## Architectural direction

- All normalized/weighted calculations use fixed-point integers; tie-breaking is deterministic.
