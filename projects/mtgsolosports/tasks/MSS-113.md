# MSS-113 — Show Chaos Cup achievements and stage paths in Athlete Profile

## Goal

Add Chaos careers to individual athlete history, including athletes from Pool.

## Context

- Project `mtgsolosports`, target `AlexBDevCorner/MtgSoloSports` (`main`). .NET + React, direct vertical-slice Endpoint → Handler, no MediatR; follow `AGENTS.md`. Approved Chaos Cup: 8 sporting colors, 1024 entrants (all source-season league athletes plus random Pool invitations), six 32-athlete group stages [32,16,8,4,2,1], top 16 from each nonfinal group; 16 game rounds per group, active bonus used but not earned; no league points/promotion, group scores reset; first draw exactly 4/color/group, later draws pure random. Runs after 32 league stages and before promotion qualifiers, only for a new season after deployment; odd/even Color/Type Cups keep alternating. Existing sporting history must remain unchanged.
- Scope: **Show Chaos Cup achievements and stage paths in Athlete Profile**. This is a single small PR, target roughly 200–600 changed lines where practical; if work expands materially, propose follow-up rather than bundling unrelated features.
- Dependencies: MSS-104, MSS-108; tasks with incomplete dependencies must wait.

## Requirements

1. Display each participated edition with attained stage, Final placement if applicable, medals and complete group trajectory with group/place links.
2. Use frozen source-tier or Pool attribution; retain Chaos trophies when an athlete later enters F3; do not give Pool automatic nationality/team eligibility.
3. Keep league championship points separate from career points and preserve existing league, Color/Type, bonus and movement sections.
4. Show absent and incomplete editions honestly; test legacy and Pool cases.

## Architectural direction

- Reuse existing feature/simulation/report patterns; keep deterministic integer calculations, save-scoped state and clear compatibility boundaries. Do not introduce MediatR or unrelated refactors.

## Acceptance criteria

- [ ] Former Pool champion retains visible historic title after future promotion to F3.
- [ ] All six-round paths and links match persisted history.

- Do not implement any other task or modify unrelated history/data merely for convenience.
