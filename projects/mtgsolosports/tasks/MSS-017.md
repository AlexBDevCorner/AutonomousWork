# MSS-017 — Rebalance feeder leagues and common pools after Superleague movement

## Goal

Return every feeder league to exactly 32 athletes after all promotion/relegation/qualifier outcomes are known.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `main`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. For each sporting color start from the previous feeder roster, remove athletes entering Superleague and add athletes returning from it.
2. If the resulting roster exceeds 32, displace the lowest-ranked eligible remaining athletes from the previous feeder season to that color's common pool.
3. If below 32, randomly draw equal-probability replacements from that color's common pool using controlled RNG.
4. Never fill pool vacancies before all qualifier/movement outcomes are resolved.
5. Former stars/common-pool athletes are eligible immediately; no cooldown or performance weighting.
6. Persist structured movement events and atomically commit RNG for pool draws.
7. Validate exactly 32 per feeder league, no active duplicates and no active athlete remaining in common pool.
8. Add edge-case tests where a color receives many relegated/failed-qualifier athletes.

## Architectural direction

- Keep rebalancing deterministic and independent per color except for shared transaction/state boundary.
