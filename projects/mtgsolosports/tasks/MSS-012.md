# MSS-012 — Add instant live-round and stage-progress UI

## Goal

Let the user trigger a round and immediately see card results and standings movement before animation work is added.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `master`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Add a live competition page for the selected league/current stage.
2. Call the existing single-round simulation endpoint and render all 32 immutable round results.
3. Show card identity/art reference, finish position, base points, active bonus, final points and rank movement/cumulative stage score.
4. Provide `Next Round` and legal stage-progress controls with disabled/loading/error states.
5. Offer an instant results mode that never performs client-side sporting calculations.
6. Allow inspecting previously completed rounds in the current stage from persisted results.
7. Keep UI state presentation-only; refreshing the page must not resimulate anything.

## Architectural direction

- The backend result is authoritative. Do not randomize, recalculate or reorder sporting outcomes in React.
