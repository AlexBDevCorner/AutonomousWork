# MSS-010 — Coordinate global stages and complete league season standings

## Goal

Make all active leagues progress synchronously through 32 stages and produce final season champions.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `main`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Track the current global stage and prevent Stage N+1 in any league until Stage N is complete for every active league.
2. Allow leagues within the current global stage to be simulated one by one.
3. Add `CompleteStageForAllLeagues` using the same underlying round/stage operations.
4. Accumulate/persist season championship standings from stage championship points.
5. After Stage 32, finalize each feeder league with deterministic complete standings and champion.
6. Persist season-level summaries sufficient for later promotion, history and selection formula.
7. Expose read endpoints for current standings and completed season table.
8. Add tests proving stage synchronization and deterministic season tie-breaking.

## Architectural direction

- Do not introduce a monolithic `SimulationService`; use focused progression slices over shared state-machine primitives.
