# MSS-016 — Implement the 32-athlete Superleague Qualifier

## Goal

Determine the final eight next-season Superleague places through the defined one-stage qualifier.

## Context

- Project: `mtgsolosports`.
- Target repository: `AlexBDevCorner/MtgSoloSports`.
- Default branch: `master`.
- Product rules: `docs/game-rules.md` in the target repository.
- Technical constraints: `docs/technical-design.md` and `AGENTS.md`.
- Architecture is vertical-slice modular monolith. **MediatR is forbidden.**
- Keep sporting simulation deterministic and use fixed-point integer arithmetic.

## Requirements

1. Build the qualifier field from 8 Superleague positions 17-24 plus feeder positions 2-4 from all eight leagues (24 challengers), exactly 32 total.
2. Run a standard 16-round stage using active career bonus and normal scoring/ranking.
3. Generate no new round or stage career bonus from the qualifier.
4. Treat incumbents and challengers identically.
5. Persist full qualifier results/history and exactly eight successful qualifiers.
6. Ensure qualifier results do not alter normal league season championship totals.
7. Add determinism/invariant tests and API/read model for result inspection.

## Architectural direction

- Reuse pure round/stage scoring primitives but keep qualifier orchestration as its own vertical slice.
