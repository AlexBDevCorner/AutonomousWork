# RM-003 — Add Copy Current Branch action

## Goal

Add a small keyboard-friendly convenience action that copies the current branch name of a selected repository to the Windows clipboard, following the existing Copy Path interaction pattern without introducing any Git mutation.

## Context

- Project: `repomanager`.
- Target repository: `AlexBDevCorner/RepoManager`.
- This is the first real implementation task intended for the full autonomous lifecycle pilot after RM-001 proved the worker integration.
- RepoManager already exposes a `CopyPathCommand`, repository context-menu actions, keyboard shortcuts, and branch presentation state through `RepositoryRowViewModel`.
- The action must remain presentation-only and MUST NOT execute Git commands or mutate repository state.

## Requirements

1. Add a `Copy Branch` action for the selected repository that copies the exact current branch name to the Windows clipboard.
2. Follow the existing `Copy Path` command and status-message patterns where practical.
3. Expose the action from the repository row context menu.
4. Add the keyboard shortcut `Ctrl+Shift+B` and include it in the application's shortcut reference/documentation where appropriate.
5. The action must be disabled when:
   - there is no selected/target repository;
   - the repository has no usable current branch;
   - the repository is in detached HEAD state.
6. On successful copy, show a status message containing the copied branch, for example `Copied branch 'main'.`.
7. Clipboard or platform failures must be handled using the same user-visible error style as the existing `Copy Path` action.
8. The implementation MUST NOT invoke Git, change branches, create branches, or otherwise mutate a repository.
9. Add or update automated tests for the behavior and UI/shortcut wiring using the repository's existing test patterns.

## Architectural direction

- Keep the feature in the WPF presentation layer.
- Prefer extending `MainWindowViewModel` and the existing context-menu/input-binding wiring rather than adding a new service or Core abstraction.
- Reuse branch state already mapped into `RepositoryRowViewModel`; do not add a Git query solely for this command.
- Preserve the existing `Copy Path` behavior unchanged.
- Follow the repository conventions in `AGENTS.md`.
- Changes should remain narrowly scoped to the action, shortcut/documentation wiring, and relevant tests.

## Acceptance criteria

- [ ] For a repository currently on `feature/foo`, invoking `Copy Branch` copies exactly `feature/foo` to the clipboard.
- [ ] The action is disabled when no repository is selected.
- [ ] The action is disabled when the current branch is unavailable.
- [ ] The action is disabled for detached HEAD.
- [ ] The repository context menu contains `Copy Branch` and displays `Ctrl+Shift+B`.
- [ ] `Ctrl+Shift+B` invokes the same command as the context-menu action.
- [ ] Successful execution produces a clear status message containing the copied branch name.
- [ ] Existing `Copy Path` behavior remains unchanged.
- [ ] No Git command or repository mutation is introduced by this feature.
- [ ] Relevant unit/UI regression tests cover the new behavior.

## Out of scope

- No branch checkout or branch switching.
- No branch creation or deletion.
- No copying of commit SHA when detached.
- No Git command added solely for this feature.
- No changes to fetch/update safety rules.
- No unrelated UI redesign or refactoring.
